# OCT Sidecar

Python sidecar service for OCT Insight Desktop Viewer.

## Overview

This module provides the Python backend services for the OCT (Optical Coherence Tomography) Desktop Viewer application, including image processing, AI/ML model inference, and data handling.

## Requirements

- Python >= 3.10
- PyTorch >= 2.0.0
- OpenCV >= 4.8.0
- llama-cpp-python >= 0.2.0
- NumPy >= 1.24.0

## Installation

```bash
uv sync
```

## Usage

```bash
python main.py
```

## Development

This project uses `uv` for dependency management. To sync dependencies:

```bash
uv sync
```
